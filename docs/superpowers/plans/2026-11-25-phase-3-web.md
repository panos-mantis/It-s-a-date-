**Goal:** Turn the `apps/web` skeleton into the app's foundation: Tailwind v4 with the Coral Friendly tokens mapped 1:1, self-hosted fonts, a tested UI kit, the router and layout, a typed API client, TanStack Query, and working log in, sign up and log out against the Phase 2 API.

Use the latest stable release of each at install time.

**Spec:** `docs/superpowers/specs/2026-11-20-its-a-date-modernization-design.md` §8.4 (and §8.3 for the auth contract). Style: `DESIGN.md` plus its machine-readable tokens in `.open-design/design-systems/style-tiles-for-it-s-a-date-a-web-app-where-peop/tokens.css`.

Two failures, two next steps. Rejected: the browser's own check or the API refuses the file (wrong type, over 5 MB with the API's 413, or not really an image). The photo is dropped, the drop zone comes back with a red edge, and the message says what to pick instead. Dropped connection: the file was fine but the upload didn't finish. The faded preview and file name stay, "Try again" re-sends the same file, and Remove clears it. In both cases the rest of the form keeps what was typed, and "Send for review" stays disabled until a photo has uploaded.
